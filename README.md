# Telecommunication-Churn-Analysis-
Telecom Customer Churn Analysis using Excel to identify churn patterns, analyze customer behavior, segment usage patterns, and generate data-driven retention insights


The Telecommunication analysis focuses on understanding customer behaviour and identifying factors that associated with customer attrition. The analysis is performed by using Microsoft Excel to explore customer account details, service usage patterns, subscription plans, and international call services. 

Analysis Performed:
1) Overall Customers
   Caluculated Total Customers, Churned Customers, Non-Churned Customers.
   Understand customer attrition.
   
2) Account Length Analysis
   Compared Account length for Churn and Non-Churn customers to determine the whether customer with shorter account shows different patterns.

3) Customer Service Call Analysis
   Created groups for the analysis based on service call frequency to calculate churn rate, investigating whether service call interactions are associated with churn.

4) Day, Evening, and Night Usage
   Comapred calling minutes and calling charges between Churn and Non-Churn customers, to explore the usage patterns between day, evening, and night.

5) Area Code Analysis
   Compared Churn and Non-Churn patterns for geographical segments.
